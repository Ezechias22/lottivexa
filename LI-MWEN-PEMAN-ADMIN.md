# Konfigirasyon peman Bolet pa admin tenant

ZIP sa a ajoute miltiplikatè peman apa pou Bolet 1ye, 2yèm ak 3yèm, san mete 60/20/10 kòm valè fiks. Admin tenant lan ale nan **Lotri ak tiraj → Règ peman pa jwèt ak pozisyon**, chwazi lotri a, kalite **BOLET**, pozisyon an epi kantite dola peman pou chak dola jwe. Li kapab mete règ jeneral pou lòt kalite jwèt, tankou Maryaj. Valè yo afekte sèlman nouvo tikè: chak tikè konsève miltiplikatè ki te anrejistre lè li te vann.

**Enpòtan:** ZIP sa a pa aktive pwomosyon 2 Maryaj gratis la. Peman Maryaj gratis ak montan li ta dwe kontwole apa, san anrejistre yon pri kòm lajan kliyan te peye. Pa prezante pwomosyon an kòm aktif.

Anvan deplwaman, fè kopi sekirite bazdone epi aplike migrasyon Prisma `0018_position_odds` sou API a; deplwaye API a anvan tenant-web ak merchant-web. Rebati APK mobil la pou aplikasyon mobil la ka chwazi pozisyon Bolet yo. Verifye premye, dezyèm ak twazyèm pozisyon sou yon tikè tès ak yon rezilta tès, san peye reyèlman. Pa pouse kòd sou Git otomatikman san ou verifye lis fichye yo.
